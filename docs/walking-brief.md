# 小镇陆地步行制作简报

目标：网页第三人称步行，原船/马车与邮路保留；所有城镇陆地通过可见桥路连通，城堡经原山路步行可达。
风格：现有纸色、淡墨线与低多边形手绘。尺度：送信人1.65m，桥面2.2m宽。新增桥梁与人物预算18000三角面，整场景上限320000；共享原材质，无新增贴图。
输出：独立walking-town.blend、walking-town.glb、walker.glb和同源walking-navigation.json；新增桥梁不封堵水路。
流程：Blender Director规划 → 原生几何建模 → 预算/坐标/材质校验 → GLB导出 → Three.js接入 → 地面碰撞与全陆地连通测试 → 实际游戏步行检查。
Blender MCP当前未连接，使用本机Blender CLI运行受版本控制的生成脚本，原场景源文件不覆盖。
