# 精致化与公开素材复用

原问题：庄园立面和两翼过于空白、屋顶只有单一体块，门廊不够明确；花园重复矩形花坛，公园缺少曲径和休憩节点；市政厅钟楼和入口缺少层次。

重点：庄园改斜坡四面屋顶、成组老虎窗和双烟囱，增加拱窗、百叶窗、门廊、墙角石饰与两翼窗饰。花坛改圆角修篱与多层花丛，中央花园有留入口的环形修篱、藤架、石花钵和侧向曲径。五处公共庭园分为凉亭、阅览、玫瑰藤架和喷泉等不同布局。市政厅补完整钟盘刻度、石饰、拱门、山花和前庭雕塑。

实际选用：Quaternius Gazebo（Poly Pizza历史发布CC0）；Poly Haven Horse Statue 01、Painted Wooden Bench（CC0）。源文件与署名/许可URL保留于source-assets。Blender移除不适合的写实材质，马雕塑简化为约1800三角面、所有资源以米制规范化，并重新映射至现有Stone/Wood/Slate纸色材质，最终同材质合并后导出。统一世界坐标纸纹与墨线，不添加运行时网络素材依赖。

预算：主城镇220000不变；街区精致化预算50000（较上一轮28000增加的空间用于建筑主入口、曲面花坛和经过简化的公共素材），材料仍复用原共享纸色。新增几何数量与实际近景画质一起验证；完整资产三角面总和目标低于300000，不以堆叠小零件替代比例调整。v1分支不变。
