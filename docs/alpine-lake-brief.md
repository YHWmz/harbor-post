# V2 湖岸雪山与融水溪谷

保留 v1（6ce44e9）于同名远端分支。主分支继续迭代。

问题：原水源是独立的窄槽，顶部只有11米高，背景山体在远处，溪流与山体没有共同的高度场。

目标：湖泊北岸紧邻三座可读的近山；山脊、雪线、汇水谷地和溪流共用一份米制高度场。主融水溪起于近山雪线附近，顺弯曲山谷下泄，坡缓处变窄、局部落差形成短瀑，末段展开为入湖河湾。两侧岩肩逐渐并入山坡，消除直立侧墙。远景雪山继续保留，城堡、邮路和湖泊主航区保持可通行。

实现：新建 tools/alpine_terrain.py 作为共享高度场和路径定义。Blender生成山体网格、雪盖和真实溪床，导出GLB；Three.js仅对现有导出水材质添加连续流动。溪谷几何和碰撞由同一源坐标产生。主城镇仍低于220000三角面，背景/近山合计目标低于15000三角面，批次按少量共享材质合并。

验证：原有五封信、返航、海滨与马车全路线；山泉由高到低连续，主溪网格贴合共享山体高度，山脚靠近湖岸，雪源位于实际山体上；浏览器白天跟船与全景检查，无渲染错误。
