# 送信人角色重制简报

使用Blender Director、Character Artist、Rigging、Animation、Asset Optimization与Export Pipeline流程。
选择Quaternius Casual Character（Poly Pizza作者原始上传，CC0）；比较Adventurer、Man in Suit后，以日常服装比例和完整手指/关节/面部选择Casual。原下载和许可随项目保留。
目标：1.74m成年邮差，原有灰绿/蓝灰/棕皮革配色，清晰鼻耳眉眼、指节、肩肘膝；订制邮政便帽、衬领、门襟与圆角翻盖邮包，信件、缝线、扣件表达职业。保留原作者骨骼/权重及Idle、Walk、Run三个循环，配件随头骨/躯干骨移动。脸部减少排线，衣服保留纸纹和轻描边。
预算：角色10000三角面以内，整场景320000以内，无写实贴图；GLB含三段骨骼动画、+Y向上、+Z朝前、脚底原点。输出blender/courier.blend、dist/assets/walker.glb和审计；网页使用AnimationMixer按速度混合动作。
验证：正侧背近景、待机/行走/快走形变、帽包跟随、脚底与比例、人物与城镇风格统一，以及步行/邮路回归。
