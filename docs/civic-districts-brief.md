# 湖岸封口与公共街区

依据用户两张截图定位：西侧城堡山脚前、东侧湖岸住宅南侧的横向支渠，均位于源坐标 z=-25，分别通往左右外海。以源坐标 x=[-104,-74]、[74,104] 和 z=[-34,-17] 的连续岸地封口，保留中央河网、湖泊入口、城堡换乘及海滨主河口。封口顶面与碰撞共享源轮廓。

东侧湖岸以庄园、轴线花园、果园菜圃和临湖餐厅替代大草坪；外侧镇街新增钟楼市政厅和前庭；西侧封口为酒庄花园，山脚外缘为葡萄园和果树；其余外围草坪以院落花坛及海边餐厅分段；崖顶边缘新增玫瑰庭园，避开城堡与马车路线。
